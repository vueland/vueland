# CMain

`CMain` — основная контентная область приложения. Растягивается на всё доступное пространство внутри [`CApp`](/ru/components/CApp) и является семантическим контейнером для основного содержимого страницы.

## Базовое использование

```html
<CApp>
  <CMain>
    <!-- содержимое страницы -->
  </CMain>
</CApp>
```

## Props

| Prop  | Тип      | По умолчанию | Описание                    |
| ----- | -------- | ------------ | --------------------------- |
| `tag` | `string` | `'div'`      | HTML-тег корневого элемента |

## Slots

| Slot      | Описание            |
| --------- | ------------------- |
| `default` | Содержимое страницы |

## CSS-переменные

`CMain` не определяет собственных CSS-переменных. Стилизуется через утилитарные классы или напрямую через селектор `.c-main`.

```scss
.c-main {
  flex: 1 0 auto;
  max-width: 100%;
}
```
