# Компоненты

Vueland UI предоставляет набор готовых компонентов для построения интерфейсов на Vue 3. Все компоненты поддерживают систему пресетов, темификацию через CSS-переменные и доступность (ARIA).

Компоненты со статусом **Stable** полностью задокументированы, покрыты тестами и готовы к использованию в продакшне. Остальные присутствуют в библиотеке, но их документация или тестовое покрытие ещё в процессе.

## Разметка

| Компонент | Статус | Описание |
|---|---|---|
| [CApp](/ru/components/CApp) | **Stable** | Корневая обёртка приложения. Управляет скроллом и создаёт контекст для оверлеев |
| [CMain](/ru/components/CMain) | **Stable** | Основная контентная область. Используется внутри `CApp` |

## Сетка

12-колоночная адаптивная сетка на flexbox. Брейкпоинты соответствуют стандарту Material Design и разделяются с утилитарными классами и `useBreakpoints`. Подробнее — в разделе [Брейкпоинты](/ru/guide/breakpoints).

| Компонент | Статус | Описание |
|---|---|---|
| [CRow](/ru/components/CRow) | **Stable** | Flex-строка. Управляет выравниванием и отступами |
| [CCol](/ru/components/CCol) | **Stable** | Колонка с адаптивной шириной, смещением и порядком |
| [CSpacer](/ru/components/CSpacer) | **Stable** | Заполняет свободное место и разделяет соседние элементы |
