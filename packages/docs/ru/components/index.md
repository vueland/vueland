# Компоненты

Vueland UI предоставляет набор готовых компонентов для построения интерфейсов на Vue 3. Все компоненты поддерживают систему пресетов, темификацию через CSS-переменные и доступность (ARIA).

## Общие

Корневые компоненты, которые оборачивают всё приложение и задают базовую разметку.

| Компонент | Описание |
|---|---|
| [CApp](/ru/components/CApp) | Корневая обёртка приложения. Управляет скроллом и создаёт контекст для оверлеев |
| [CMain](/ru/components/CMain) | Основная контентная область. Используется внутри `CApp` |

## Поля формы

Компоненты для построения форм с валидацией, состояниями и пресетами.

| Компонент | Описание |
|---|---|
| [CForm](/ru/components/CForm) | Обёртка формы. Координирует валидацию всех дочерних полей |
| [CTextField](/ru/components/CTextField) | Текстовое поле с плавающим лейблом, иконками и подсказкой |
| [CInput](/ru/components/CInput) | Функциональная основа всех полей. Управляет состоянием, валидацией и пресетами |

## Сетка

12-колоночная адаптивная сетка на flexbox. Брейкпоинты соответствуют стандарту Material Design и разделяются с утилитарными классами и `useDisplay`. Подробнее — в разделе [Брейкпоинты](/ru/guide/breakpoints).

| Компонент | Описание |
|---|---|
| [CRow](/ru/components/CRow) | Flex-строка. Управляет выравниванием и отступами |
| [CCol](/ru/components/CCol) | Колонка с адаптивной шириной, смещением и порядком |
| [CSpacer](/ru/components/CSpacer) | Заполняет свободное место и разделяет соседние элементы |
