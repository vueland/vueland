Polished date controls for production usage.

Updated `CDatePicker` selection, navigation, focus and dark-theme states, and aligned the selected/current/disabled visuals across day, month and year views. Refactored the picker view API names to read by intent: `showNextPage`, `showPreviousPage`, `toggleView` and `showToday`.

Improved `CDateInput` nullable value handling, date bounds, typed input, presets and forwarded picker slots. Expanded public API test coverage for date picker/input behavior and refreshed documentation examples with responsive utility layouts and `CIcon` slot usage.
